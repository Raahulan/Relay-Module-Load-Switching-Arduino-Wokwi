# Upload to GitHub

**Suggested repository name:** `Relay-Module-Load-Switching-Arduino-Wokwi`

**Description (copy/paste):**
Arduino UNO relay-switching demonstration with a pushbutton, LED load indicator, serial monitoring, and Wokwi circuit simulation.

1. Extract the GitHub ZIP locally.
2. Sign in to [GitHub](https://github.com/) and open [New repository](https://github.com/new).
3. Enter the suggested name and description, set visibility to Public if desired, and create the repository **without pre-creating a README**.
4. Select **Add file → Upload files**.
5. Drag all files and folders **inside the extracted project directory** onto the upload panel. Do not upload just the ZIP.
6. Use commit message `Initial commit - Relay Module Load Switching Wokwi project`.
7. Click **Commit changes** and confirm README displays the circuit screenshot.

To open the simulation, follow the README's Wokwi instructions. The ZIP is a project archive, not an automatically published Wokwi project URL.
